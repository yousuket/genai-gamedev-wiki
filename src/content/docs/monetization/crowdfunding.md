## 概要

クラウドファンディング（クラファン）は、完成前のゲームへの支援をインターネットで募り、見返り（リターン）としてゲームや特典を渡す仕組みです。ゲームの場合は「購入型」と呼ばれる形式が一般的です。

この記事では次のことが分かります。

- Kickstarter・CAMPFIREを日本から使う条件と手数料（2026年9月時点）
- 始める前に準備すること
- よくある失敗パターンと、税金の基本的な考え方

## クラファンは「資金集め」より「ファン集め」

個人開発でクラファンを使う目的は、主に次の3つです。

- **開発資金**: 外注費（音楽・イラストなど）やツール代をまかなう。
- **需要の確認**: お金を払ってでも欲しい人がどれだけいるかを確かめる。
- **コミュニティづくり**: 支援者は、発売後にも応援してくれる最初のファンになる。

ただし、クラファンは**すでにファンがいる人ほど成功しやすい**仕組みです。Kickstarterでは目標に届かないと資金を受け取れないため、「告知すれば人が集まる」わけではありません。ウィッシュリストやSNSでファンを集めることが先です（[ウィッシュリストの集め方](/monetization/wishlists/)）。

## 主なサービスの比較

| 項目 | Kickstarter | CAMPFIRE |
|---|---|---|
| 主な支援者 | 世界中（英語圏が中心） | 日本国内 |
| 日本からの利用 | 可能（条件あり） | 可能 |
| 方式 | 目標達成時のみ資金を受け取る（All-or-Nothing） | All-or-Nothing と All-in（目標未達でも受け取る）を選べる |
| 手数料 | 5%＋決済手数料4.5%（日本のプロジェクト） | 12%＋決済手数料5%（税別） |
| 目標未達時 | 支援者に請求されず、手数料もかからない | All-or-Nothingなら手数料なし |

（2026年9月時点。出典は以下の各節）

国内には他にもMakuake、READYFORなどのサービスがあります。

## Kickstarter

- **日本からの利用条件**: 日本はプロジェクトを立ち上げられる国に含まれています。個人の場合は、18歳以上で日本に住んでいて日本の政府発行の身分証を持っていること、本人名義の日本の銀行口座、本人名義のクレジットカードまたはデビットカードが必要です（[Who can use Kickstarter](https://help.kickstarter.com/hc/en-us/articles/115005128594-Who-can-use-Kickstarter)、2026年9月時点）。
- **手数料**: 成功したプロジェクトから、Kickstarterの手数料5%と決済手数料が引かれます。日本のプロジェクトの決済手数料は4.5%です（[Fees: Japan](https://www.kickstarter.com/help/fees?country=JP)、2026年9月時点）。
- **All-or-Nothing**: 目標に届かなければ、支援者には誰にも請求されません。Kickstarterはこれを「お店との違い」と説明しています（[Why is funding all-or-nothing?](https://help.kickstarter.com/hc/en-us/articles/115005047893-Why-is-funding-all-or-nothing)）。
- **AI利用の開示**: 生成AIを使ったプロジェクトは、申請時とプロジェクトページで、どのAI技術をどう使うか、どこが自分のオリジナルでどこがAI出力を使った部分かを開示する必要があります（[Can I use AI-generated content...](https://help.kickstarter.com/hc/en-us/articles/16848396410267-Can-I-use-AI-generated-content-or-create-AI-technology-in-my-project)）。開示が不十分だとプロジェクトが停止される可能性があります（[Kickstarterの発表](https://updates.kickstarter.com/introducing-our-new-ai-policy/)）。ストアでのAI開示全般は [プラットフォームのAIポリシー](/legal/platform-policies/) を参照してください。
- **言語**: 支援者の多くは海外にいるため、ページや動画は英語で用意するのが前提になります。

## CAMPFIRE

- **手数料**: 通常のCAMPFIREは、プロジェクトが成立した場合に支援総額の12%（利用手数料）＋5%（決済手数料）に消費税を加えた額を支払います（[CAMPFIRE掲載時の手数料](https://help.camp-fire.jp/hc/ja/articles/115013873328-CAMPFIRE%E6%8E%B2%E8%BC%89%E6%99%82%E3%81%AE%E6%89%8B%E6%95%B0%E6%96%99)、2026年9月時点）。掲載料・初期費用はかかりません（[CAMPFIREアカデミー](https://camp-fire.jp/academy/articles/crowdfunding-fees-explained)）。
- **方式**: All-or-Nothing方式では目標未達なら支援金は全額返還され、手数料もかかりません。All-in方式では目標に届かなくても集まった金額を受け取れます（同上）。All-inを選ぶ場合は、目標未達でもリターンを必ず届ける前提で計画してください。
- **エンタメ向けの枠**: 「CAMPFIRE for Entertainment」では、手数料（利用0〜12%、決済0〜5%）をオーナーと支援者がそれぞれ負担する形で設定できます（[CAMPFIRE掲載時の手数料](https://help.camp-fire.jp/hc/ja/articles/115013873328-CAMPFIRE%E6%8E%B2%E8%BC%89%E6%99%82%E3%81%AE%E6%89%8B%E6%95%B0%E6%96%99)）。

## 準備の進め方

1. **遊べるものを先に作る**: デモや、面白さの核が伝わるバーティカルスライス（完成品と同じ品質で作った一部分）があると信頼されます。
2. **目標金額を逆算する**: 「本当に必要な最低額」に、手数料・リターンの制作費・送料・税金を加えて計算します。
3. **リターンを絞る**: 最初はデジタル版のゲーム・クレジット表記・サウンドトラックなど、**送料のかからないもの**を中心にします。
4. **ページと動画を用意する**: 何を作るのか、いつ届くのか、誰が作るのかを明確にします。動画の作り方は [Steamトレーラーの要件](/trailer/steam-trailer/) の記事も参考になります。
5. **公開前にファンに知らせる**: 開始直後の勢いが重要です。SNSやメールで事前に告知しておきます。
6. **[Steam](https://store.steampowered.com/)のストアページも並行して用意する**: 支援者以外の人もウィッシュリストに登録できるようにしておきます。

## よくある失敗パターン

| パターン | 何が起きるか | 対策 |
|---|---|---|
| ファンがいない状態で開始 | 支援が集まらず目標未達 | 先にSNSやウィッシュリストで関心を集める |
| 目標金額が高すぎる | 期間内に届かない | 最低限必要な額に絞り、追加目標（ストレッチゴール）で上積みする |
| 物理リターンが多い | 制作費・送料が想定を超えて赤字 | デジタルリターン中心にする。送料は国別に見積もる |
| 開発期間の見積もりが甘い | 納期遅れで支援者の信頼を失う | スコープを小さくし、余裕を持った日程を示す |
| 途中報告をしない | 不安や不満が広がる | 定期的に進捗を報告する |
| AI利用の説明不足 | 批判を受けたり、審査で止まったりする | どこにAIを使ったかを最初から明記する |

[Steam](https://store.steampowered.com/)は早期アクセスについて「開発資金を集める手段ではない」としています（[Early Access](https://partner.steamgames.com/doc/store/earlyaccess)）。クラファンも同じで、**支援が集まらなくても完成させられる計画**を立てておくのが安全です。

## 税金の基本

- 購入型クラファンの支援金は、個人の場合「事業所得」または「雑所得」になります。受け取った時点では「前受金」として扱い、リターンを提供した時点で売上に計上する、という考え方が一般的です（[弥生: クラウドファンディングで確定申告は必要？](https://www.yayoi-kk.co.jp/shinkoku/oyakudachi/crowdfunding/)）。
- プラットフォーム手数料やリターンの制作費・送料は経費になります（同上）。
- リターンの提供は消費税の対象になりえます。
- 年をまたぐプロジェクトでは計上時期の判断が難しくなります。

## AIの活用ポイント

- **ページの翻訳**: Kickstarter向けの英語ページの下書きにAI翻訳が使えます。
- **予算表の作成**: 手数料・リターン原価・送料・税金を含めた予算表をAIに作らせ、目標金額の妥当性を検討できます。
- **進捗報告の下書き**: 定期報告の文章づくりにAIを使うと、報告を続けやすくなります。
- **AI利用の開示文**: 「どこにAIを使い、どこを自分で作ったか」を整理した開示文の下書きにもAIを使えます。
