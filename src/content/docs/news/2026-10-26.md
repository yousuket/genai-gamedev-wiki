## 今週のハイライト

### Unity CLI の実行の約98%がコーディングエージェント経由

Unity が Unity CLI の利用データを公開しました。7月以降、ログイン済みユーザー22万6,000人以上が使い、2026年7月20日〜10月13日の実行の約98%が、コーディングエージェントなどの自動化によるものでした。人の直接実行は0.2%です。公式プラグインは Claude Code・Codex・Grok の3つで、`unity setup claude` で Claude Code 用を導入できます。Cursor や Cline は、プラグインなしでも CLI 経由で操作できます。Unity でエージェントを使う場合、CLI が標準の入口になりつつあります。

- 出典: [Unity ブログ](https://unity.com/blog/unity-cli-usage-data-ai-coding-agents)

### GameMaker の新ランタイム GMRT が2027年1月1日から無料に

Game Developer によると、Opera 傘下の GameMaker は、新ランタイム GMRT を2027年1月1日から全開発者に無料にします。これまでは PC・モバイル・ブラウザ・GX Games へ出すにも Professional ライセンスが必要でした。記事は、GMRT に Claude Code を使うAI開発のワークフロー向けのツール群が含まれると書いています。PS5・Xbox Series X|S・Switch 2 向けは引き続き Enterprise ライセンスが必要です。

- 出典: [Game Developer](https://www.gamedeveloper.com/programming/gamemaker-s-gmrt-runtime-will-soon-be-free-for-all-commercial-devs)

### AIによる逆コンパイル移植が急増、一方で「クローン」への警戒も

The Verge は、AIツールで古いゲームを解析し、別の環境向けに作り直す移植が急増していると報じました。Halo のブラウザ版や Wind Waker の iPhone 版が例で、ゲーム保存コミュニティは割れています。個別事例として、Claude に archive.org の zip を渡し、2000年代初期のオランダ製教育ゲームを逆コンパイルしてブラウザで遊べるようにした記録も出ました。一方、自作が先にクローンされることを恐れ、Moonlighter の開発元は新作の公開プレイテストを取りやめ、Discord 限定の小規模テストに切り替えました。非公式の Daggerfall オンライン化プロジェクトが Patreon で月約1,253ドルを集めて批判された件もあり、既存作品をAIで再現して収益を得る場合の権利リスクは高いままです。

- 出典: [The Verge](https://www.theverge.com/ai-artificial-intelligence/1015430/ai-retro-games-decomp-recomp-port)、[bou.ke](https://bou.ke/blog/zoetermeer/)、[Game Developer](https://www.gamedeveloper.com/programming/moonlighter-developer-delays-public-playtest-of-next-game-over-concerns-of-ai-cloning)、[Automaton](https://automaton-media.com/articles/newsjp/20261019-474335/)

### Steam のパーソナルカレンダーが正式機能に

Steam の「パーソナルカレンダー」が Steam Labs を卒業し、正式機能になりました。プレイ時間の長いゲームをもとに、似たプレイ傾向のユーザーがウィッシュリストに入れた・遊んでいるゲームを、今後8週間のカレンダー形式で薦めます。推薦は毎日再学習されます。ほかに Automaton は、10月の Next Fest の体験版が約7200本で6月の約1.7倍、AI使用を開示した Steam ゲームが2026年は約1万700本（SteamDB の集計）と報じています。競争が激しくなっているため、発売日とストアページを早めに整える価値があります。

- 出典: [Steam 告知](https://store.steampowered.com/news/app/593110/view/710037059469839718)、[Automaton](https://automaton-media.com/articles/newsjp/20261020-474386/)

### AI ジャムが続々と、ルールはジャムごとに逆

Epic の「2026 Epic AI MegaJam」（11月12〜15日、UE / UEFN、AIエージェントは何体でも可、賞金$65,000）と、Unity の「Official 2026 Unity Game Jam」（11月5日開始、生成AIは開示すれば可）が発表されました。一方、Pixel Forge MEGA JAM（11月28日開始）は生成AIをすべて禁止しています。参加前に規約の確認が必要です。

- 出典: [2026 Epic AI MegaJam](https://itch.io/jam/2026-epic-ai-megajam)、[Official 2026 Unity Game Jam](https://itch.io/jam/official-unity-game-jam-2026)、[Pixel Forge MEGA JAM](https://itch.io/jam/pixel-forge-mega-jam)
