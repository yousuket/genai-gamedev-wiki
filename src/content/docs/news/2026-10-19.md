## 今週のハイライト

### Google が Gemini 4 Argon を公開

10月13日、Google が Gemini 4 Argon を公開しました。AI Studio と Gemini API で使え、Google AI Ultra 加入者は Antigravity でも使えます。導入価格は入力100万トークンあたり$2、出力$10で、2026年11月30日までの期間限定です。その後は入力$4、出力$20になります。公式ブログには、外部ライブラリなしでブラウザ上に描画する3Dゲームのデモが載っていますが、ゲーム制作向けの性能比較は書かれていません。使うなら、導入価格のうちに試すのが現実的です。

- 出典: [Google ブログ](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/)

### 逆コンパイル・コミュニティ decomp.dev が閉鎖、AIによる移植・改造が急増

ゲームの逆コンパイル・改造を扱う decomp.dev の管理者は、AIで簡単になりすぎて人間主導のプロジェクトとAI生成物の区別もつかなくなったとして、10月15日に閉鎖を発表しました（404 Media）。Kotaku は、Claude Opus 5.5 以降にブラウザ移植や逆コンパイル・再コンパイルが急増し、GitHub に公開される DMCA 削除通知にゲーム会社の件が多いと報じています。一方で Microsoft は、ゲームの逆コンパイルを試す小さなチーム「Xbox Labs」を新設したと報じられました。既存ゲームをAIで移植・改造する場合の権利リスクは、先週の削除事例に続いて高まっています。

- 出典: [404 Media](https://www.404media.co/video-game-reverse-engineering-community-shuts-down-because-ai-has-made-it-too-easy/)、[Kotaku](https://kotaku.com/ai-vibe-coding-just-hit-the-video-game-industry-like-an-avalanche-2000746366)、[The Verge](https://www.theverge.com/news/1010406/xbox-labs-game-decompiling-emulation-exploration)

### Epic が新ストアを「全面バイブコーディング」と説明

Destructoid によると、Epic は新しい Epic Games Store（テスト提供中）を AI コーディングエージェントだけで作ったと説明しています。初回起動の読み込みが Steam の約2倍速いと主張していますが、第三者の検証は確認できていません。VGC は、Epic が未発表作の開発でも「手書きコードをやめる」と開発者に伝えたと報じています（元の Bloomberg 記事は未確認）。個人制作者への具体的な影響（Unreal の料金・ツール変更）は、報道には書かれていません。

- 出典: [Destructoid](https://www.destructoid.com/epic-games-store-ai-vibe-coded/)、[VGC](https://www.videogameschronicle.com/news/epic-games-reportedly-orders-staff-to-implement-ai-first-development/)

### Steam のウィッシュリストが「インフレ」、購買率は約半分に

Chris Zukowski 氏が160タイトルのデータを分析しました。2020〜2022年発売の34本と2023〜2025年発売の126本を比べると、発売時のウィッシュリスト数に対する販売本数の比率（中央値）は、発売1か月・6か月時点で約半分に下がっています。数年前の「ウィッシュリスト数×一定比率」で売上を見積もると、過大になりえます。

- 出典: [Automaton](https://automaton-media.com/articles/newsjp/20261017-474077/)

### SQUARE ENIX GAME CONTEST 2026 の詳細

賞金総額10億円（最優秀1作品3億円、傑作賞4作品が各1億円、優秀賞10作品が各3000万円）。応募受付は2026年12月15日〜2027年3月15日23時59分で、個人も応募できます。AIについては、応募規約とは別に「AI利用ガイドライン」を設け、応募開始直前までベータ版とのことです。中身は未公開のため、AI利用の可否は分かっていません。

- 出典: [Automaton](https://automaton-media.com/articles/interviewsjp/square-enix-game-contest-20261014-473272/)

### エージェント開発・事例

- Claude Opus 5.5 に完全な自律権限を与え、AI業界を題材にした3Dブラウザゲームを GitHub Pages に公開させた記録。→ [ポン出し](/agent-dev/one-shot/)（[出典](https://blog.fsck.com/2026/10/11/picks-and-shovels/)）
- ゲーム開発向けの「AIハーネス」設計の解説。乱数シード固定、画像差分での確認、数値の外部化など。著者は大規模なゲーム向けの手法だと述べています。→ [検証ループ](/agent-dev/verification-loop/)（[出典](https://kylekukshtel.com/ai-harness-engineering-game-development-claude-code)）
- Epic の動向（上記）。→ [概要](/agent-dev/overview/)
- Anthropic が、エージェントによるマージが10倍超に増えたため、社内のバージョン管理を git から自作の「Scion」に置き換えた経緯を公開。個人制作者がこの規模になることはまずありませんが、エージェントがバージョン管理の使い方を変えうる、という参考になります。（[出典](https://www.anthropic.com/engineering/redesigning-source-control)）
- Claude Code チームのコードレビュー運用。リスクで変更を分け、低リスクは人の承認なし、中リスクは1人、高リスクは2人としています。（[出典](https://claude.dev/blog/solving-code-review-at-anthropic/)）
