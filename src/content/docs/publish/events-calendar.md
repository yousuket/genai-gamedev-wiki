## 概要

ゲームジャム（決まった期間で、お題に沿ってゲームを作るイベント）やコンテストへの出品は、締切があり、作った作品を見てもらえる場でもあるので、個人開発のモチベーションになります。この記事は、**どんなイベントが、いつあるのか、あったのか**を一覧にしたものです。

- 2026年9月29日時点で、公式ページに日程が出ているものだけを載せています。日程が出ていないイベントは「未発表」と書き、日付は推測していません。
- [itch.io](https://itch.io/) のジャムの日時は、ジャムのページに表示される UTC です。日本時間は +9 時間です。
- AI や生成AIの扱いは、公式ルールに書かれている内容です。ルールに書かれていないものは「規定なし」としています。
- AI・バイブコーディング系（[Vibe Jam](https://vibej.am/)、AI Browser Game Jam）は、「開催済み」の節で詳しく書いています。

ジャムへの参加の進め方は [ゲームジャムに出す](/publish/game-jams/)、作品の置き場所は [itch.io に公開する](/publish/itch-io/) を見てください。

## AIの扱いの違い

同じジャムでも、AIの扱いは正反対に分かれます。ルールを読まずに出すと、失格になります。

| 区分 | イベント |
|---|---|
| 必須 | Cursor [Vibe Jam](https://vibej.am/)（2026年は、コードの90%以上をAIが書く）、AI Browser Game Jam（大半をAIが生成）、Slapjam AI |
| 許可（条件付きを含む） | [Global Game Jam](https://globalgamejam.org/)（制限なし）、[Ludum Dare](https://ldjam.com/)（生成AIが大半を担った部門はオプトアウト）、SQUARE ENIX GAME CONTEST 2026（使用ツールの開示と権利保証が必須）、Godot Japan Game Jam（任意。他者の権利を侵害する素材は禁止） |
| 制限 | GMTK Game Jam（アートと音声の生成AIは禁止、それ以外も使わないよう求める）、Mini Jam（画像や音声を作る生成AIのほとんどは禁止） |
| 禁止 | Brackeys Game Jam、Godot Wild Jam（バイブコーディングを含む）、Pirate Software Game Jam、GBJAM（AIのコード生成を含む）、SCREAM JAM、Kenney Jam（AI補助のコードも対象） |
| 規定なし | [js13kGames](https://js13kgames.com/)、Game Off、GDevelop BIG Game Jam、Official Unity Game Jam 2026、Mini Jame Gam、Unity 1週間ゲームジャム |

- AIで作った作品を出すなら、「必須」か「許可」の区分から選びます。
- 「禁止」のジャムでも、Ludum Dare のように部門ごとのルールを持つ場合や、GMTK のように一部だけ禁止する場合があります。
- 出典は、それぞれの公式ページです。[Ludum Dare のAIについての FAQ](https://ludumdare.com/resources/questions/can-i-use-ai/)、[Global Game Jam のAIポリシー](https://globalgamejam.org/news/global-game-jam-artificial-intelligence-policy)、[GMTK Game Jam 2026](https://itch.io/jam/gmtk-jam-2026)、[Brackeys Game Jam 2026.2](https://itch.io/jam/brackeys-16)、[Godot Wild Jam #98](https://itch.io/jam/godot-wild-jam-98)、[Pirate Software Game Jam 20](https://itch.io/jam/pirate)、[GBJAM 14](https://itch.io/jam/gbjam-14)、[SCREAM JAM 2026](https://itch.io/jam/scream-jam-2026)、[Kenney Jam 2026](https://itch.io/jam/kenney-jam-2026)、[Mini Jam 220](https://itch.io/jam/mini-jam-220-crystal)、[Godot Japan Game Jam 2026](https://godot-japan.com/game-jam/)（いずれも2026年9月29日時点）。

### AI・バイブコーディング系

#### Vibe Jam（levelsio 氏主催）

[Vibe Jam](https://vibej.am/) は、Pieter Levels（levelsio）氏が開く、AIで書いたゲームのジャムです。2025年と2026年に開かれています。

| 項目 | 2025年 | 2026年 |
|---|---|---|
| 公式の名前 | Bolt Vibe Coding Game Jam 2025 | Cursor Vibe Jam 2026 |
| スポンサー | Bolt.new、CodeRabbit、Lambda | Cursor、Bolt.new、Glif、Tripo AI |
| 期間 | 公式の応募一覧の登録日時は2025年3月17日〜4月2日。結果発表は4月23日 | 2026年4月1日〜5月1日（13:37 UTC）。結果発表は6月17日 |
| 規模 | 1,000本超の応募 | 945作品、プレイヤー延べ1,371,866人 |
| 賞金 | 1位10,000ドル、2位5,000ドル、3位2,500ドル（合計17,500ドル） | 1位25,000ドル、2位10,000ドル、3位5,000ドル、特別賞12件が各1,000ドル |
| AIの規則 | コードや素材の80%以上をAIが書く | コードの90%以上をAIが書く |
| 主な入賞作 | 1位 The Great Taxi Assignment、2位 Vibeware、3位 Vector Tango | 1位 A Game About Capybaras Delivering Food、2位 Fanto's Mega-Mart、3位 WenWare |

共通の条件は、ログインや登録なしで遊べること、無料であること、ローディング画面や重いダウンロードがないこと、専用ドメインまたはサブドメインに置くことです。2026年は、そのほかに次の条件がありました。

- ジャム開始（2026年4月1日）より前に存在したゲームは出せない
- 1人1作品
- 公式のウィジェット（JavaScript の1行）を入れる。入っていないと失格
- どのエンジンでもよいが、Three.js が推奨されている

2026年の審査員は、levelsio 氏、s13k_ 氏、Tim Soret 氏、Nicola Manzini 氏、Eric Zakariasson 氏（Cursor のデザイナー）、Alessandro Schiassi 氏です。levelsio 氏の発表では、審査員全員が昨年より作品の質がずっと高いと評価しています。2025年の審査員は、Andrej Karpathy 氏、Tim Soret 氏、mrdoob 氏、s13k_ 氏、levelsio 氏でした。

2026年の1位は、[A Game About Capybaras Delivering Food](/cases/browser-capybara/) です。

出典: [Cursor Vibe Jam 2026（公式）](https://vibejam.com/)、[Press Release](https://vibejam.com/2026/press)、[Bolt Vibe Coding Game Jam 2025（公式）](https://vibejam.com/2025/)、[2026年の結果（levelsio）](https://levels.io/vibe-jam-2026-winners-quality)、[2025年の結果（levelsio）](https://levels.io/winners-of-the-2025-vibe-code-game-jam)（2026年9月29日時点）

#### AI Browser Game Jam（Focaccai 主催）

[itch.io](https://itch.io/) で開かれる、AIで作るブラウザゲームのジャムです。特定のサービスの利用を条件にせず、どのAIをどこに使ってもよい、と主催者が書いています。2026年に4回開かれ、第5回が10月17日から始まります。

| 回 | 期間（2026年） | テーマ | 投稿数 / 参加登録数 |
|---|---|---|---|
| 第1回 | 2月20日〜3月10日（締切を延長） | Ghost in the Machine | 29 / 50 |
| 第2回 | 4月11日〜4月30日 | Alien | 47 / 104 |
| 第3回 | 6月6日〜6月24日 | Familiar | 82 / 119 |
| 第4回 | 8月1日〜8月18日 | CHARGE! | 126 / 248 |
| 第5回 | 10月17日〜10月31日 | 開始時に発表 | 参加登録42人（開催前） |

- 投稿数と参加登録数は、主催者が第5回のページに書いている数字です（2026年9月29日時点）。
- 第1回〜第3回のルールは、ブラウザで遊べることと、AIが50%以上を生成していること。第4回・第5回は、AIが大半を生成していること、既存プロジェクトの続きは新しい内容が大半であれば可、複数作品を出せること（内容が十分に違うこと）が加わりました。
- 評価の部門は、総合、楽しさ、グラフィック、オーディオ、テーマ、AIの使い方の6つです（第4回・第5回）。
- 第4回の1位は [Plug & Prosper](/cases/browser-plug-prosper/) です。

出典: [第1回](https://itch.io/jam/ai-browser-game-jam)、[第2回](https://itch.io/jam/ai-game-jam-2)、[第3回](https://itch.io/jam/ai-game-jam-3)、[第4回](https://itch.io/jam/ai-jam-4)、[第5回](https://itch.io/jam/ai-jam-5)（2026年9月29日時点）

## イベントの見つけ方（itch.io のジャムページ）

[itch.io の Game jams](https://itch.io/jams) は、世界中のジャムが集まる一覧です。ここまでに載せたイベントの多くは、このページで見つかります。2026年9月29日時点で、開催予定は約240件、開催中は約220件が並んでいます（[開催予定](https://itch.io/jams/upcoming)、[開催中](https://itch.io/jams/in-progress)）。全部を見る必要はなく、次の手順で絞れます。

1. **トップの [/jams](https://itch.io/jams)** を開くと、上部に「Upcoming This Month（今月始まる）」「Featured Jams（注目）」「Top Past Jams（過去の人気）」「In Progress（開催中）」「Jam Calendar（カレンダー）」が並びます。まずカレンダーで、月ごとの開催を見ます。
2. **[開催予定の一覧](https://itch.io/jams/upcoming)**（Explore All Jams）では、上のタブで「Upcoming（これから）」「Starts This Week（今週始まる）」「Starts This Month（今月始まる）」「In Progress（開催中）」「Ended（終了）」を切り替えます。
3. **並び順**は、「Most Joined（参加登録が多い順）」と「Starting Soon（開始が近い順）」です。参加者の多いジャムを探すなら「Most Joined」、直近を探すなら「Starting Soon」です。
4. **絞り込み**は、「Entries Ranked（順位を付ける）」「No Ranking（順位なし）」「Featured（注目）」「Has Participants（参加登録がある）」です。順位を付けるジャムは、評価とコメントがもらえます。
5. **個別のジャムのページ**に、開始日と終了日、投票の終了日、参加登録数、ルールが載っています。AIの扱いは、ここのルールの欄で確認します。「Join jam」を押すと、参加登録できます。
6. **過去のジャム**は、[Top Past Jams](https://itch.io/jams/past) で見られます。参加者の数や、勝った作品を調べるのに使えます。

[itch.io](https://itch.io/) のジャムページには、ジャムのために作られたゲームが累計603,865本あると書かれています（2026年9月29日時点）。

itch.io 以外では、[Ludum Dare](https://ldjam.com/) は [ldjam.com](https://ldjam.com/)、[Global Game Jam](https://globalgamejam.org/) は [globalgamejam.org](https://globalgamejam.org/)、[js13kGames](https://js13kgames.com/) は [js13kgames.com](https://js13kgames.com/)、[Vibe Jam](https://vibej.am/) は [vibejam.com](https://vibejam.com/)、Unity 1週間ゲームジャムは [unityroom](https://unityroom.com/unity1weeks) で、それぞれ日程を確認できます。

[Steam](https://store.steampowered.com/) のデモ公開イベントである Steam Next Fest は、ジャムとは別のイベントです。[ウィッシュリストを増やす](/monetization/wishlists/) に書いています。
