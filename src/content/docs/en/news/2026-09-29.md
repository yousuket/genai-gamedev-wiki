## This week's highlights

### Claude Sonnet 5.5 released (same pricing, 30%+ faster)

Anthropic released Claude Sonnet 5.5, its mid-tier model, on September 28, 2026. Output is 30% or more faster than Sonnet 5, and it requires fewer tokens for the same task, so cost per task is said to drop as much as 30%. API pricing remains unchanged at $2 per 1 million input tokens, $10 per 1 million output tokens, and $0.20 per 1 million cache-read tokens.

For solo developers who run coding agents daily, the same budget now allows you to run more experiments.

- Source: [Anthropic official](https://www.anthropic.com/claude-sonnet-5-5) (as of September 2026)
