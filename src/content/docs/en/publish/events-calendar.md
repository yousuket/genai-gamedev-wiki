## Overview

Participating in game jams (events where you make a game in a set period around a theme) or contests provides motivation for solo development because they have deadlines and offer an audience for your work. This article lists **what kinds of events exist, when they happen, and when they happened**.

- As of September 29, 2026, only events with confirmed dates on their official pages are included. Events without announced dates are marked "not yet announced" without any date guesses.
- Times for [itch.io](https://itch.io/) jams are shown in UTC on the jam page. Japan Standard Time is UTC+9.
- AI and generative AI policies are taken from the official rules. Events without rules on this topic are marked "no policy."
- AI and vibe coding jams ([Vibe Jam](https://vibej.am/), AI Browser Game Jam) are covered in detail in the "Past events" section.

For how to participate in jams, see [Entering a game jam](/en/publish/game-jams/). For where to share your work, see [Publishing on itch.io](/en/publish/itch-io/).

## AI Policy Differences

Events split in opposite directions on AI. Disqualification can happen if you do not read the rules.

| Category | Events |
|---|---|
| Required | Cursor [Vibe Jam](https://vibej.am/) (2026: 90%+ of code by AI), AI Browser Game Jam (majority by AI), Slapjam AI |
| Allowed (including conditions) | [Global Game Jam](https://globalgamejam.org/) (no restrictions), [Ludum Dare](https://ldjam.com/) (opt out if AI did most of the work), SQUARE ENIX GAME CONTEST 2026 (disclosure of tools used and rights guarantee required), Godot Japan Game Jam (optional; no assets infringing others' rights) |
| Restricted | GMTK Game Jam (no AI art or audio; others discouraged), Mini Jam (most image and audio AI prohibited) |
| Prohibited | Brackeys Game Jam, Godot Wild Jam (including vibe coding), Pirate Software Game Jam, GBJAM (includes AI code generation), SCREAM JAM, Kenney Jam (AI-assisted code counts) |
| No policy | [js13kGames](https://js13kgames.com/), Game Off, GDevelop BIG Game Jam, Official Unity Game Jam 2026, Mini Jame Gam, Unity 1-Week Game Jam |

- If you want to submit AI-made games, pick from "Required" or "Allowed."
- Some "Prohibited" jams like Ludum Dare have per-category rules, or like GMTK, only ban certain uses.
- Sources are the official pages: [Ludum Dare AI FAQ](https://ludumdare.com/resources/questions/can-i-use-ai/), [Global Game Jam AI Policy](https://globalgamejam.org/news/global-game-jam-artificial-intelligence-policy), [GMTK Game Jam 2026](https://itch.io/jam/gmtk-jam-2026), [Brackeys Game Jam 2026.2](https://itch.io/jam/brackeys-16), [Godot Wild Jam #98](https://itch.io/jam/godot-wild-jam-98), [Pirate Software Game Jam 20](https://itch.io/jam/pirate), [GBJAM 14](https://itch.io/jam/gbjam-14), [SCREAM JAM 2026](https://itch.io/jam/scream-jam-2026), [Kenney Jam 2026](https://itch.io/jam/kenney-jam-2026), [Mini Jam 220](https://itch.io/jam/mini-jam-220-crystal), [Godot Japan Game Jam 2026](https://godot-japan.com/game-jam/) (all September 29, 2026).

### AI and Vibe Coding

#### Vibe Jam (hosted by Pieter Levels)

[Vibe Jam](https://vibej.am/) is an AI-game jam by Pieter Levels (levelsio). It has run in 2025 and 2026.

| Item | 2025 | 2026 |
|---|---|---|
| Official name | Bolt Vibe Coding Game Jam 2025 | Cursor Vibe Jam 2026 |
| Sponsors | Bolt.new, CodeRabbit, Lambda | Cursor, Bolt.new, Glif, Tripo AI |
| Duration | Official entry list: Mar 17–Apr 2, 2025. Results announced Apr 23 | Apr 1–May 1, 2026 (13:37 UTC). Results announced Jun 17 |
| Scale | Over 1,000 submissions | 945 games, 1,371,866 player sessions |
| Prize money | 1st $10,000, 2nd $5,000, 3rd $2,500 (total $17,500) | 1st $25,000, 2nd $10,000, 3rd $5,000, 12 special awards of $1,000 each |
| AI requirement | 80%+ of code and assets by AI | 90%+ of code by AI |
| Top winners | 1st The Great Taxi Assignment, 2nd Vibeware, 3rd Vector Tango | 1st A Game About Capybaras Delivering Food, 2nd Fanto's Mega-Mart, 3rd WenWare |

Common rules: playable without login or signup, free, no heavy loading screens or downloads, hosted on a dedicated or subdomain. 2026 added:

- No games made before the jam started (April 1, 2026)
- One game per person
- Must include the official widget (one line of JavaScript). Failure to include means disqualification
- Any engine OK, but Three.js recommended

The 2026 judges were Pieter Levels, s13k_, Tim Soret, Nicola Manzini, Eric Zakariasson (Cursor designer), and Alessandro Schiassi. In Pieter's announcement, all judges said the quality was much higher than 2025. The 2025 judges were Andrej Karpathy, Tim Soret, mrdoob, s13k_, and Pieter Levels.

The 2026 winner was [A Game About Capybaras Delivering Food](/en/cases/browser-capybara/).

Sources: [Cursor Vibe Jam 2026 (official)](https://vibejam.com/), [Press Release](https://vibejam.com/2026/press), [Bolt Vibe Coding Game Jam 2025 (official)](https://vibejam.com/2025/), [2026 results (Pieter Levels)](https://levels.io/vibe-jam-2026-winners-quality), [2025 results (Pieter Levels)](https://levels.io/winners-of-the-2025-vibe-code-game-jam) (September 29, 2026)

## Finding Events (itch.io Jams Page)

[itch.io's Game jams](https://itch.io/jams) is a global jam list. Many of the events above are on this page. As of September 29, 2026, about 240 upcoming and 220 in-progress jams are listed ([upcoming](https://itch.io/jams/upcoming), [in progress](https://itch.io/jams/in-progress)). You do not need to see all; narrow down with these steps:

1. **Start at [/jams](https://itch.io/jams)**. The top shows "Upcoming This Month," "Featured Jams," "Top Past Jams," "In Progress," and "Jam Calendar." Check the calendar first for monthly events.
2. **[Upcoming list](https://itch.io/jams/upcoming)** (Explore All Jams): tabs at the top let you switch between "Upcoming," "Starts This Week," "Starts This Month," "In Progress," and "Ended."
3. **Sorting**: "Most Joined" (most registered) or "Starting Soon" (earliest start). Use "Most Joined" for popular jams, "Starting Soon" for what is coming up.
4. **Filters**: "Entries Ranked" (has voting and comments), "No Ranking" (no voting), "Featured," "Has Participants." Ranked jams give feedback on your game.
5. **Individual jam pages** list start/end dates, voting end date, registered count, and rules. AI policy is in the rules section. Click "Join jam" to register.
6. **Past jams** are on [Top Past Jams](https://itch.io/jams/past). Use this to check participation numbers and winning games.

itch.io's jam page says 603,865 games total have been made for jams (September 29, 2026).

Outside itch.io, check [Ludum Dare](https://ldjam.com/) at [ldjam.com](https://ldjam.com/), [Global Game Jam](https://globalgamejam.org/) at [globalgamejam.org](https://globalgamejam.org/), [js13kGames](https://js13kgames.com/) at [js13kgames.com](https://js13kgames.com/), [Vibe Jam](https://vibej.am/) at [vibejam.com](https://vibejam.com/), and Unity 1-Week Game Jam at [unityroom](https://unityroom.com/unity1weeks).

[Steam](https://store.steampowered.com/)'s demo festival, Steam Next Fest, is a separate event. See [Growing wishlists](/en/monetization/wishlists/).
