## 概要

[Steam](https://store.steampowered.com/)のストアページでは、トレーラーがスクリーンショットより前に表示され、訪問者が最初に目にする要素の1つになります。

この記事では、[Steamworks](https://partner.steamgames.com/)（Steamの開発者向け管理画面とドキュメント）の公式情報をもとに、次のことをまとめます。

- アップロードする動画の技術仕様
- 表示順・カテゴリ・マイクロトレーラーの仕組み
- カプセル画像（ストアに並ぶゲームのサムネイル画像）との関係
- 公開前に確認すべき点

構成の考え方は [PVの構成](/trailer/structure/)、書き出しの手順は [画面キャプチャと編集ツール](/trailer/capture-and-editing/) を参照してください。

## 技術仕様

[Steamworks: トレーラー](https://partner.steamgames.com/doc/store/trailer) に記載された仕様です（2026年9月時点）。

| 項目 | 仕様 |
|---|---|
| 解像度 | 最大1920×1080 |
| アスペクト比 | 16:9推奨（4:3も可） |
| フレームレート | 30/29.97fps または 60/59.94fps |
| ビットレート | 5,000kbps以上の高ビットレート |
| コンテナ | .mov / .wmv / .mp4 |
| 映像コーデック | H.264推奨 |
| 音声コーデック | AAC推奨。変換時にステレオへまとめられる |
| サンプルレート | 44kHz または 48kHz |

Adobe Media Encoder向けには「H.264 Video（20Mbps）＋AAC Stereo Audio（192kbps）」のプリセットが案内されています。

### 変換に失敗するとき

公式のFAQでは、変換失敗のよくある原因として次の2つが挙がっています。

- 標準的でない解像度 → 1920×1080か1280×720にする
- 対応していない音声サンプルレート → 44kHzか48kHzにする

### 変換待ちの注意

- アップロード後の変換は順番待ちで、**数時間かかる** ことがあります。再アップロードすると順番が最後に戻ります。
- **トレーラーの変換中はゲームをリリースできません**。発売日の直前にアップロードしないようにしましょう。

## ストアページでの表示

### 表示順とカテゴリ

- **最初の2本の有効なトレーラー** がスクリーンショットより前に表示され、3本目以降はスクリーンショットの後に並びます。順番は管理画面でドラッグして変更できます。
- トレーラーには「一般／シネマティック」「ティーザー」「ゲームプレイ」「インタビュー／開発日記」のカテゴリを付けられ、ストア上でトレーラー名の横に表示されます。

[Steamworks](https://partner.steamgames.com/)は、**先頭にはゲームプレイ中心のトレーラーを置く** よう勧めています。プレイヤー視点で「ゲームの中で何をするのか」を見せ、HUDも入っていたほうが判断しやすいことが多い、としています。

### 見られ方の前提

Steamworksのドキュメントは、次の2点を前提に作るよう述べています。

- ディスカバリーキュー（おすすめのゲームを順に見せる機能）では、印象を残せる時間が **10秒未満** のことがある
- **音声なし** で見られている可能性がある

なお、ストアページを開いたときに自動再生されるか、音声がミュートで始まるかといった既定の挙動は、Steamworksの公式ドキュメントには明記されていません（2026年9月時点）。ユーザーの設定や環境によっても変わりうるため、**音がなくても内容が伝わる映像にし、重要な情報は文字でも示しておく** のが安全です。

### 2025年のプレイヤー刷新

Valveは2025年7月30日にトレーラープレイヤーを刷新しました（[Steam Trailer Player Upgrades](https://store.steampowered.com/news/app/593110/view/500579723494031419)）。主な変更点は次のとおりです。

- 360p／480p／720p／1080pの最大4種類の画質を用意し、回線とプレイヤーの大きさに応じて自動で切り替える
- シークバーにマウスを乗せると、移動先のプレビュー画像が出る
- デスクトップ、モバイル、[Steam](https://store.steampowered.com/) Deck、Big Pictureモードに合わせてUIが変わる
- どんなアスペクト比の動画も、拡大・中央寄せ・黒帯追加で正しく表示する

シークバーのプレビューにより、視聴者は気になる場面へ飛びやすくなりました。1ショットごとに内容が伝わる構成にしておくと、飛ばし見でも伝わります。なお、アスペクト比は表示できるようになりましたが、アップロード仕様としては引き続き16:9が推奨です。

## マイクロトレーラー

マイクロトレーラーは、[Steam](https://store.steampowered.com/)が自動生成する短いループ動画です。公式FAQによると（2026年9月時点）、次のように作られます。

- ストアページで **最初に表示されるトレーラー** から作られる
- 動画のさまざまな位置から1秒ずつ6カ所を切り出し、つないだ **6秒** のループ
- 開発者がカスタマイズすることはできない

ストア上でカプセル画像にマウスを乗せたときのプレビューなどに使われますが、表示される場所の一覧は公式ドキュメントには書かれていません（2026年9月時点）。この機能は、Steam Labsの実験機能として始まったものです（[Steam Labs - Micro Trailers](https://store.steampowered.com/labs/microtrailers)）。

つまり、**先頭のトレーラーはどこを切り出されても内容が伝わる** ほうが有利です。ロゴや黒画面、文字だけの画面が長く続くと、マイクロトレーラーに使われたときに何のゲームか伝わりません。

## カプセル画像との関係

カプセル画像はトレーラーとは別に登録する静止画で、検索結果やセール一覧などに表示されます（[Steamworks: グラフィカルアセット](https://partner.steamgames.com/doc/store/assets)）。

| 画像 | サイズ（2026年9月時点） |
|---|---|
| ヘッダーカプセル | 920×430 |
| スモールカプセル | 462×174 |
| メインカプセル | 1232×706 |
| バーティカルカプセル | 748×896 |

カプセル画像のルールも確認しておきましょう（[Graphical Asset Rules](https://partner.steamgames.com/doc/store/assets/rules)、2022年9月1日から適用）。

- 基本のカプセルに載せてよいのは、ゲームのアートワーク、ゲーム名、公式のサブタイトルだけ
- レビュースコア、受賞歴、割引の宣伝文句、他製品の宣伝は載せられない
- 大型アップデートやDLCの告知などは、期間1カ月までの「アートワークオーバーライド」で一時的に表示できる

実務上は、**カプセル画像で興味を持った人が、トレーラーで「期待どおりのゲームだ」と確認できる** ように、絵柄や雰囲気をそろえることが大切です。カプセルだけ豪華なイラストで、トレーラーの映像と印象が大きく違うと、期待外れに感じられやすくなります。

### トレーラーのサムネイル

[Steam](https://store.steampowered.com/)は各トレーラーから、ポスター画像（600×380）とサムネイル（232×130）を自動生成します。自分で指定する場合は、**その動画の中の1フレーム** を1920×1080の.jpgか.pngでアップロードします。

## 多言語・地域別の設定

「詳細設定」で、言語別のトレーラーを登録したり、国ごとに表示を制限したりできます。基本の動画は英語版にし、国はISO 3166-1 alpha-2のコード（例: `JP,US`）で指定します。

## 公開前チェックリスト

- [ ] 先頭のトレーラーは「ゲームプレイ」カテゴリで、最初の数秒にゲームプレイがある
- [ ] 音声なしでも何のゲームか分かる
- [ ] どこを6秒切り出されても内容が伝わる（ロゴや黒画面が長く続かない）
- [ ] 1920×1080、30fpsか60fps、H.264＋AAC（44.1kHzか48kHz）で書き出している
- [ ] 発売日やイベントの数日前までにアップロードし、変換が終わっている
- [ ] カプセル画像とトレーラーの雰囲気がそろっている
- [ ] 映像がゲームの実際の内容と一致している（[AI動画生成の使いどころ](/trailer/ai-video/)）

ストアページ全体でウィッシュリストを集める方法は [ウィッシュリストの集め方](/monetization/wishlists/)、[Steam](https://store.steampowered.com/)のその他のルールは [プラットフォームのAIポリシー](/legal/platform-policies/) を参照してください。

## AIの活用ポイント

- **仕様チェックの自動化**: `ffprobe` の出力をLLMに渡し、「[Steamworks](https://partner.steamgames.com/)の仕様（解像度、fps、コーデック、サンプルレート）を満たしているか」を確認させられます。変換失敗を減らせます。
- **多言語版の準備**: タイトルカードの文言や字幕を翻訳させ、言語別トレーラーの下準備に使えます。

```sh
# 書き出したファイルの解像度・fps・コーデック・サンプルレートを確認する
ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate,sample_rate -of compact trailer.mp4
```
