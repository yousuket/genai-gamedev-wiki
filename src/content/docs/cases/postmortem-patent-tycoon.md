## 概要

Patent Tycoon は、知財関係の仕事をしている開発者「トラステ」氏（Steam の開発元名は Torasute）が作った、特許を武器にする経営シミュレーションです。発明、出願、ライセンス交渉、訴訟で会社を育てます。
2025年9月1日に「ChatGPT でゲームを作ってみよう」と思い立って開発を始め、開発ログを note に毎日投稿しました。コードは約9万行で、開発者本人は「コードは100%生成AIが書き、自分では編集していない」と書いています。
体験版を2025年12月17日、製品版を2026年4月17日に、どちらも無料で Steam に公開しました。開発者は起動数やプレイ時間などの統計を、公開10日後に数字つきで公表しています。

## 何が作られたか

ゲームの核は、製薬、機械、ソフトウェアの3産業で、研究開発、特許の出願、ライセンス契約、訴訟を進めて企業を成長させる経営シミュレーションです。開発者は、経営ゲームの Victoria 3 を参考に、簡略化した経営の仕組みを目指したと書いています。
ストアページの紹介文によると、周回するたびに深まるストーリーと、経営シムには珍しいボス戦があります。案内役のAI「アキ」と謎の「トラ猫」が登場し、プレイヤーは「100人目の挑戦者」という設定です。
体験版から製品版までの更新で、社員の採用ガチャ、企業のDNAによる引き継ぎ要素、スコアアタックモード、AI企業の性格のランダム化などが加わっています。

## 進め方（どうポン出しから製品にしたか）

開発者の note から、進め方の変化を時系列で整理します。

### 1. ChatGPT のチャットだけで作ろうとして詰まった（1〜5日目）

最初は、ChatGPT のチャット画面でコードを書かせ、コピー・貼り付けで動かしていました。仕様書は ChatGPT の Canvas 機能で、「ChatGPT が議題を出して案を書く、人がOKか修正を伝える」を繰り返して作り、2日で約1.5万字（原稿用紙78枚分）になりました。
しかしコードが約1,000行、18ファイルほどになった段階で、コピー・貼り付けの往復ではデバッグが収束しなくなりました。

### 2. コーディングエージェントに切り替えた（6日目〜）

6日目に Codex を使い始め、そこから開発の速度が変わったと本人は書いています。使い方は次のとおりです。

1. GitHub にリポジトリを作る
2. Web版の Codex（のちに Claude Code）にプロンプトを渡し、ブランチとプルリクエストを作らせる（1回約5分）
3. ローカルの VS Code でそのブランチを動かして確かめる
4. よければマージ、だめなら修正を依頼する

操作するコマンドは、ブランチの取得（チェックアウトとプル）と `npm run electron` の実行だけだったと述べています。コードを本人が編集しないまま、16日目に1万行、100日目に約7.5万行（コメントを含めて約8.8万行）になりました。
コーディングAIは途中で Claude Code 主体に切り替えました。理由は、Codex は最小限しか話さないのに対し、Claude Code は相談にも乗ってくれて対話しやすいからだと書いています。

計画が怪しい依頼は、Codex の「プランモード」（実装せず相談だけするモード）で認識をそろえてから頼む、と決めていました。

### 3. 見た目と音もAIに作らせた

- 背景イラスト: メイン画面は、部屋の配置という論理構造を守れる DALL-E 3 で作り、各部屋の人物は Midjourney で描かせた
- レイアウト: 現在の画面のスクリーンショットを Nano Banana に渡して案を出させ、その画像を Claude Code に渡して「この画像のレイアウトにして」と頼んだ
- BGM: 画面の絵を ChatGPT に見せて Suno AI 用のプロンプトを作らせ、約30曲を生成して選んだ

画面は開発の途中で、1920×1080と2560×1440などの解像度・拡大率に対応するため、レイアウトを0から作り直しています（36〜41日目）。

### 4. 遊んでもらう準備に時間を使った（50日目〜）

開発が形になった50日目ごろから、マーケティングに移りました。

- X のアカウントを0から作り、note の自動宣伝投稿も試した
- 63日目に Steamworks に登録し、69日目にストアページの審査に申請
- 80日目ごろ、ココナラでテスターを雇い、バグとチュートリアルの改善点を集めた
- 99日目（2025年12月8日）に体験版を Steam の審査に提出した

## 独自性をどこで出したか

- **題材が開発者の仕事そのもの。** 特許という地味な題材を、本人の専門知識で経営シムにしています。ストアページも「特許を武器に」を前面に出しています。
- **ゲームの型は借りて、そこに物語を足した。** 経営ゲームの構造は Victoria 3、UIと音楽は Persona 5 を参考にし、経営シムに周回型のストーリーとボス戦を組み合わせました（本人の記述）。
- **画面の絵にキャラクターの世界観を通した。** 各サブ画面に人物を置き、メイン画面でその人たちが見渡せる構成にして、AI生成の絵に統一感を持たせました。
- **開発ログそのものを宣伝にした。** 毎日 note に投稿し（マガジンは67本）、のちに X に移しました。

## うまくいかなかったこと

- **ChatGPT のチャットでの開発。** 1週間で行き詰まり、コーディングエージェントに切り替えるきっかけになりました（前述）。
- **X 広告の効果を読み違えた。** ストアページの公開直後の3日でウィッシュリスト（発売通知を受け取る登録。ここでは発売前の関心の指標）が約1,800件つきましたが、本人が調べると大半は電ファミニコゲーマーの記事からの流入でした。広告は縮小して停止しています。
- **ストアページの審査で2回戻された。** 1回目は、AIの利用説明文の英語が抜けていたこと、2回目（体験版）は、ストアの画像の数とサイズの不整合が理由でした。
- **公開直後のバグでパニックになった。** 体験版の公開後に自分で遊ぶと、Steam 経由でのみ背景画像が出ない不具合がありました。修正を繰り返して30分間直せず、公開を停止する方法を探すのにさらに10分かかり、公開から約40分が過ぎました。約190人がライブラリに登録した中で、10分以内に離脱したのは約70人だったと述べています。本人の教訓は「公開後にバグが見つかった場合の手順を、あらかじめ決めておく」です。
- **序盤の離脱。** 体験版でも製品版でも、初回の10分で離脱する人が4割強いました。チュートリアルの文章を減らし、特許になじみのない人向けに平易にする修正を重ねています。
- **大型タイトルとの重なり。** 製品版の公開週には、ほかの大型ゲームが立て続けに発売され、可処分時間を取られやすいと開発者は懸念しています。

## 結果

製品版の公開後、開発者は次の数字を公表しています（2026年4月20日と4月28日のnote）。

| 指標 | 値 |
|---|---|
| 公開3日後のプレイ人数 | 約140人 |
| 最後の実績（おまけエピソード）の解除率 | 11.8%（公開3日後） |
| ライブラリ登録数（Lifetime free licenses） | 9,276件（公開10日後） |
| 起動数（Lifetime unique users） | 221件（起動率は約2.4%） |
| 平均プレイ時間 | 1時間23分 |
| プレイ時間の中央値 | 14分 |
| 10分未満で離脱 | 43% |
| 10時間以上遊んだ人 | 2%（20時間以上は1%） |
| ストアページの訪問数 | 1日あたり約300（うち外部リンクからが約100、ディスカバリーキューと新作キューから各30〜40） |

ライブラリ登録数は、無料ゲームで「ライブラリに追加する」だけで増える数字です。実際にプレイした人数は起動数の221件に当たります。開発者はこの起動率について、無料ゲームでは妥当な範囲だとAIに確認しています。
Steam のレビューは、2026年9月29日時点で7件（好評4件、不評3件）です。無料のため、売上はありません。次回作は探偵もので、ストアページを公開済みです。

## 学べること

- **チャット画面でのコピー・貼り付け開発は、規模が大きくなると行き詰まる。** 本人の場合は約1,000行・18ファイルで収束しなくなり、リポジトリを読めるコーディングエージェントに変えた時点で速度が別物になったと述べています。ツール選びは [AIコーディングツール](/dev-env/ai-coding-tools/) を参照してください。
- **エンジニアでなくても、Gitの最小限で9万行に届く。** 使った操作は、ブランチの取得、実行、マージだけです。ただし、何を作るか、どの絵を採用するかの判断（OKを出す、選ぶ）は本人が行っています。
- **発売前の関心は、ウィッシュリストで測る。** この事例では、X広告よりもゲームメディアの記事の方が効きました。ウィッシュリストの基本は [ウィッシュリスト](/monetization/wishlists/) を参照してください。
- **初回10分の離脱が、無料ゲームでも最大の課題になる。** 起動した人の4割強が10分以内に離れています。チュートリアルの改善が、公開後の更新の中心になりました。
- **公開の手順と停止の手順は、事前に決めておく。** 体験版の公開で背景が出ないバグを踏み、約70人が最初の10分で離れました。
- **AIの利用開示を、英語でも忘れずに出す。** 審査で戻された原因のひとつです。詳細は [プラットフォームのポリシー](/legal/platform-policies/) を参照してください。
