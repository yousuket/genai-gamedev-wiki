## 概要

CODEX MORTIS は、開発者 GROLAF 氏（パブリッシャー名 CRUNCHFEST）が「コード、テキスト、絵、音、音楽のすべてにAIを使った」と Steam のストアページに明記して販売している、ネクロマンサーが主人公の見下ろし型の弾幕サバイバー（Vampire Survivors 系）です。
最初の試作は約3か月で作られ、2025年12月にデモ、2026年3月26日に早期アクセス、2026年9月24日に1.0が公開されました。
AI製であることを隠さず、むしろ前面に出して売った点が特徴で、公開当初は海外メディアや Steam のコメントで批判を集めました。2026年9月時点の Steam のレビューは、全言語で92件中70件が好評です。売上や販売本数は公表されていません。

## 何が作られたか

Steam のストアページによると、遊びの中心は「出撃前にスペルでデッキを組み、ゾンビの群れの中で戦う」ことです（2026年9月時点）。

- 敵の大群を倒して育つ、弾幕系のローグライト（1回ごとに強化を選んで遊ぶ形式）
- 10系統のダークマジックと合計200種のスペル。どの系統も互いに組み合わせられる
- スペルを変質させる「ミューテーション」。2026年5月の時点で249個
- 得たポイントでブースターパックを開き、スペルの手持ちを増やすデッキ構築
- 31人の主人公、14ステージ、3つのゲームモード、パスワード付きの最大4人オンライン協力

ストアページには、AIの利用範囲が次のように開示されています。

> AI is used for entire code of the game, text, arts, sounds and music.

ゲームエンジンは使わず、TypeScript で描画に PixiJS、エンティティ管理に bitECS、デスクトップ化に Electron を使っています。開発者は Reddit に「Claude Code（主に Opus 4.1 と 4.5）でバイブコーディングした」と書き、絵は ChatGPT の通常版で作り、アニメーションは Claude Code が書いたシェーダーで表現したと述べています（PC Gamer の記事が投稿を引用。2025年12月）。

## 進め方（どうポン出しから製品にしたか）

開発者は YouTube の解説動画の説明欄で、「使えるAIモデルを片っ端から試して、1本のゲームを作った」という趣旨を述べています。試作はチャット画面から始まったと、1.0公開時の告知にも書かれています。ポン出しの先の進め方は、Steam の告知から追えます。

| 時期 | 内容 |
|---|---|
| 2025年12月 | デモを公開。ウィッシュリスト登録を呼びかけ。年末に無料のデモ限定ステージを追加 |
| 2025年12月〜2026年2月 | 早期アクセス版の設計を公開。「8ステージ、それぞれ違う仕組み」を方針にし、Discord で試作版のベータテストを募集 |
| 2026年2月23日〜3月2日 | Steam Next Fest（体験版を集めて遊んでもらう期間限定イベント）に参加。専用ステージを追加 |
| 2026年3月26日 | 早期アクセス開始（予定より1週間延期）。10%オフで販売 |
| 2026年3月31日〜4月29日 | 約1か月で「コミュニティ更新」を15回。バグ修正、サバイバーモード、エンドゲームの成長要素、リーダーボード、Steam Deck 検証など |
| 2026年5月21日 | 「ミューテーション」を追加（31スキルに249個）。レベルアップの選択肢を5枚から3枚に |
| 2026年8月 | 見下ろしから等角投影に変更。全キャラのスプライトを描き直し、系統を5から10へ、主人公を31人に |
| 2026年9月11日〜24日 | デッキ構築とブースターパックを導入。オンライン協力を追加し、1.0を公開 |

読み取れる進め方は、次のとおりです。

- **公開版と試験版を分けた。** 安定版のほかに、Discord の参加者向けに不安定なベータ版を置き、変更を先に試してもらっています。「1,500個のミューテーションを検証中」と告知し、実際に載せたのは249個でした。
- **1つの更新は小さくした。** 1回の更新で、スペル2つや1つのステージなどの単位で出し、更新のたびに告知しています。
- **遊びの中心を、公開後に作り直した。** 早期アクセスの終わりに、視点を変え、デッキ構築とブースターパックを導入しました。ポン出しの延長ではなく、遊ばれた結果をもとにした再設計です。

## 独自性をどこで出したか

- **「AI製」を売りにした。** デモの告知に「100% AI-driven development」と書き、トレーラーには「AI antis」と書かれた悪魔を倒す場面がありました（PC Gamer の記事）。早期アクセスの告知には「あなたのお気に入りのAIスロップゲーム」と自嘲する言い方が使われています。
- **ジャンルの定番に、系統の組み合わせとデッキ構築を足した。** 開発者側は「Vampire Survivors に Guild Wars 風のビルドを合わせた」と紹介しています（Insider Gaming の記事が引用）。
- **ステージごとに違う仕組み。** 例として、ボスを弱らせるために建物を壊す、5本の柱を90秒ずつ守る、上昇する虚無から逃げる、などがあります（Steam の告知）。
- **プレイヤーと一緒に作る姿勢。** 告知の署名は「CRUNCHFEST & GROLAF」で、Discord とフォーラムの要望を更新内容に挙げています（1.0の告知）。

絵柄は、報道では「ぼんやりして見分けにくい」と評されました（PC Gamer）。1.0に向けて、全スプライトを新しい視点に合わせて作り直しています。

## うまくいかなかったこと

- **公開当初の批判。** Insider Gaming は、コメント欄の反応を「魂のないスロップ」と書く声が中心だったと伝えています。PC Gamer は「初の完全AI製」という主張を疑問視しました。Steam のコミュニティにも、返金したという投稿があります。
- **約束した機能の遅れ。** 1.0のお知らせに、「オンライン協力は早期アクセス初日に約束した唯一の機能で、ようやく入った」とあります。約束から実装まで約6か月かかりました。
- **数値のバランス崩れ。** クールダウン短縮を積むとゼロになり、毎フレームスキルが発動して画面が読めなくなったため、「詠唱時間」という別の数値を全スキルに追加しました（8月7日の告知）。
- **公開直後の不具合。** 早期アクセス直後の修正では、敵の出現タイマーがポーズ中も進む問題（実時間で動いていた）、ボスの攻撃タイマーが初期化されない問題などが出ています（3月31日の告知）。1.0直後にも、Steam Deck とLinuxのローカル協力が動かなくなっていたのを戻しています（9月29日の告知）。
- **アニメーション。** 開発者は、キャラクターのアニメーションがうまく作れず、シェーダーで揺らす方式にしたと述べていると報じられています（Interesting Engineering。開発者のコメントを伝える二次情報）。5月21日の更新では、全キャラと全敵にアニメーションが付いたと告知しています。

## 結果

- Steam のレビューは、全言語で92件中70件が好評で、評価は「やや好評（Mostly Positive）」です（Steam レビュー集計、2026年9月29日時点）。
- 価格は定価3.99ドルで、1.0の公開時に30%引きの2.79ドルにしています（Steam ストア、2026年9月29日時点）。
- 売上、販売本数、デモのダウンロード数、ウィッシュリストの数は、開発者・パブリッシャーとも公表していません。
- 1.0の公開と同時に、制作の全体像を語る約15分の動画「How I made a game using ONLY AI (full story)」を YouTube に公開しています。

## 学べること

- **AI製だと表示することは、販売の障壁と宣伝の両方になる。** 批判は避けられませんでしたが、開示を隠さない姿勢のまま更新を続け、2026年9月時点のレビューは「やや好評」です。開示の書き方は [プラットフォームのポリシー](/legal/platform-policies/) を参照してください。
- **初期版をポン出しで作り、遊びの中心は公開後に作り直せる。** 視点、デッキ構築、系統の数は、早期アクセスの期間中に大きく変わりました。ポン出しから製品にする考え方は [ポン出しから製品へ](/agent-dev/from-one-shot-to-product/) にまとめています。
- **数値の暴走は、詠唱時間のような別の上限で抑える。** 強化を積み上げて成立する遊びでは、上限のない数値が画面を壊します。
- **小さな更新を、頻繁に、告知と一緒に出す。** 約1か月で15回の更新は、少人数でも回せた運用です。
- **エンジンなしでも出せるが、プラットフォーム連携は自分で作る。** Electron 版のSteam連携は、UnityやUnrealほど滑らかではないと、開発者が述べていると報じられています（Interesting Engineering）。
