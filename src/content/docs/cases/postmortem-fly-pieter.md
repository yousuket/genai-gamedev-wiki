## 概要

fly.pieter.com は、個人開発者の Pieter Levels 氏（X: @levelsio）が2025年2月22日に作り始めたブラウザの飛行機ゲームです。ゲーム開発は初めてで、Cursor に「ブラウザで、高層ビルのある3D飛行ゲームを作って」と頼んだのが出発点でした。
約3時間で遊べる状態になり、その後の開発と公開を、本人が X でほぼリアルタイムに実況しました。ゲームは無料で、収入源は「広告飛行船」などのゲーム内広告枠とF-16の課金（29.99ドル）です。
開始から17日目に、広告枠の予約を月額換算した売上が8.7万ドル（年換算100万ドル）に達したと本人が報告しています。作者自身は後にこのプロジェクトを「稼げたが持続しなかった」側に分類しています。

## 何が作られたか

Microsoft Flight Simulator の起動やアップデートを待たずに、すぐ遊べる飛行機ゲームです。作者は自分のサイトに書いた経緯で、この動機を説明しています。
2025年2月22日の最初のプロンプトは次の1文でした。

```text
make a 3d flying game in browser with skyscrapers
```

出典は本人のX投稿です（[投稿](https://x.com/levelsio/status/1893350391158292550)）。本人は「多くの質問とコメントを重ねて」、素のHTMLとJavaScriptによる飛行シミュレーターに仕上げたと書いています。同日中に、次の機能が追加されました。

- 弾を撃つ、建物や船を壊す
- スマートフォン用の仮想ジョイスティック（読者の提案で nippleJS を採用）
- 8時間目にマルチプレイ（PeerJS と WebRTC）

2月25日にはサーバーを作り直し、全員が同じ世界を飛ぶ形にしました。Python の WebSocket サーバーを Grok 3 に書かせ、全プレイヤーの位置を100ミリ秒ごとに集めて配る仕組みです（[投稿](https://x.com/levelsio/status/1894429987006288259)）。
その後、ドッグファイト（撃墜）、体力表示、ミニマップ、リーダーボード、チャット、機体の選択（セスナ172、F-16、A-10、対空戦車、UFO）が加わりました。

## 進め方（どうポン出しから製品にしたか）

ポン出し（一発生成）は最初の3時間だけで、その後はほぼ毎日、機能を1つずつ頼んで、遊んで、直す繰り返しでした。本人の投稿から、進め方の特徴を拾います。

- **公開しながら作った。** ゲームは1日目からURLを公開し、遊んだ人の提案（WebRTC、nippleJS、FOVを速度で広げる小技など）を次々に取り込んでいます。
- **難しい依頼は、AIに任せる範囲を変えた。** サーバーの通信は Cursor から Grok 3 に切り替えました。PeerJS は基本的にP2Pで限界があると判断し、WebSocket に移したのは作者です。
- **性能問題は、詳しい人の助言で解決した。** 滑走路の照明を PointLight から発光マテリアルに変えるだけで、一部の端末で8FPSが60FPSになる可能性があるという Three.js の助言を取り込んでいます（[投稿](https://x.com/levelsio/status/1897728697253453865)）。
- **AIが得意な依頼と苦手な依頼を見分けた。** 対空戦車は Cursor と Claude が一発で作りました。一方、宙返りができる飛行モデルは「Claudeに5回頼んでも直らず、変更のたびに新しい問題を伝え続けた」と述べています（[投稿](https://x.com/levelsio/status/1896308800895987743)）。

## 独自性をどこで出したか

飛行の操作感やグラフィックスは、AIが作った一般的なものです。独自性は、ゲームの外側にありました。

- **ロードのない、すぐ遊べる無料MMO。** 起動の遅い既存の飛行ゲームへの不満から出発し、URLを開くだけで全員が同じ空を飛べる形にしました。
- **広告枠を売る収益化。** 2月26日に PHOTOAI（作者自身のサービス）の広告飛行機を飛ばし、同日に Stripe の購入ボタンを付けてF-16を29.99ドルで売り始めました。その後、外部の企業に広告飛行船、雲、月と火星などの枠を売っています。
- **作者の既存の観客。** 作者は大量のフォロワーを持っており、開発の実況自体が宣伝でした。作者は自分のサイトで、この一連の投稿がX上で1億回を超えて表示されたと書いています（誰かが数えたものと紹介）。

## うまくいかなかったこと

ここまでの記録に出てくる問題を、日付順に並べます。

| 2月24日 | Cursorが既存の関数を直さず、同名の関数を追加していた。JavaScriptでは後の定義が上書きするので、エラーが出なかった。本人はSonnet 3.5の文脈量の限界が原因だろうと推測している | 原因と対処を投稿で共有した（[投稿](https://x.com/levelsio/status/1894052988655906896)） |
| 2月28日 | 無料マルチプレイゲームに、全員を撃墜するbotが現れた | Cloudflare の CAPTCHA を追加。ただし「効くのは1日だけかも」とも述べている（[投稿](https://x.com/levelsio/status/1895614492752703800)） |
| 3月2日 | 三角形の「UFO」が飛び回り、ほかのプレイヤーを撃ち始めた。作者が実装したものではなく、改造した参加者によるものと本人は見ている | 仕組みはよく分からないと述べつつ、そのコードを標準機能として取り込んだ（[投稿](https://x.com/levelsio/status/1896213286737350769)） |
| 3月2日〜3日 | M3 MacBook が省電力モードになるとFPSが落ち、ゲーム全体の速度まで落ちた | 物理更新の間隔を描画のFPSから切り離した（Claudeが生成したコード） |
| 3月10日 | サーバーのログが16GBに膨らんでディスクが満杯になり、動作が遅くなった | ログの書き出しを直した（[投稿](https://x.com/levelsio/status/1899065515596722414)） |

作者はこの状況を、無料マルチプレイゲームの問題を一気に体験していると、冗談まじりに書いています（[投稿](https://x.com/levelsio/status/1895608319127273954)）。

## 結果

売上は、すべて作者のX投稿による報告です。金額は、広告枠の月額契約を月額換算した見込みが中心で、実際の入金額は公表されていません。

| 日付（2025年） | 報告された数字 |
|---|---|
| 2月27日 | F-16が9本（約270ドル）、広告飛行船が1枠（1,000ドル）。累計8.9万人がプレイ、同時飛行の最大は2.6万機、モバイル比率63% |
| 3月2日（9日目と本人が表記） | F-16が12本（約360ドル）、広告枠17件（月17,000ドル）で月17,360ドル。枠の価格を月2,500ドルに引き上げた |
| 3月3日（10日目） | 広告枠19件（月38,000ドル）とF-16で月38,360ドル。この日のプレイヤーは約1.6万人 |
| 3月6日（13日目） | 月67,000ドル |
| 3月10日 | 1日の最高記録3.1万人、月72,000ドル、累計29.6万人 |
| 3月11日（17日目） | 月87,000ドル（年換算100万ドル）。累計32万人。広告枠は残り3つ |

（[3月2日](https://x.com/levelsio/status/1896282625985102042)、[3月3日](https://x.com/levelsio/status/1896690611257844116)、[3月6日](https://x.com/levelsio/status/1897784027186446820)、[3月10日](https://x.com/levelsio/status/1899166414667178314)、[3月11日](https://x.com/levelsio/status/1899596115210891751)、[2月27日](https://x.com/levelsio/status/1895126942233350340) の投稿）

MRR は Monthly Recurring Revenue（毎月入る見込みの売上）の略です。広告枠は月額で売られていたため、この数字は「毎月更新されれば」という前提の見込みです。3月3日の内訳では、F-16が約360ドルに対し広告枠が月38,000ドルで、収入の大半は広告枠でした。

その後について、作者は自分のプロジェクト一覧で fly.pieter.com を「Okay: Took off, Made money but not sustainable（伸びて稼いだが、持続しなかった）」に分類しています（[List of all my projects ever](https://levels.io/projects)、2026年9月時点）。ゲームは2026年9月29日時点でも遊べ、ゲーム内広告の募集とF-16（29.99ドル）が表示されています。
第三者の記事（DEV Community の Promptway 記事）は、2026年半ばの作者のXプロフィールで、この事業の月額が0ドルと表示されていると伝えています。これは二次情報で、本稿では確認していません。

## 学べること

- **ポン出しは入口にすぎない。** 3時間で遊べる状態にはなりましたが、価値が出たのは、その後の2週間で「他人と同じ空を飛ぶ」体験を足したことです。ポン出しから製品にする考え方は [ポン出しから製品へ](/agent-dev/from-one-shot-to-product/) を参照してください。
- **1ファイルに全部入れると、AIの編集が遅く、不安定になる。** 3,000行の時点で、変更に15秒かかり、重複した関数が生まれました。ファイルを分けて依頼することが、早い段階で必要になります。
- **収益はゲーム価格ではなく、観客と広告枠から来た。** 売り物は、遊んでいる人の目の前に置ける広告枠でした。売上の大半を占めたのは、ゲーム内課金（F-16）ではなく広告枠です。
- **一発生成の弱点は、公開してすぐに見つかる。** 通信の設計、bot、改造、ログのディスク満杯は、遊ばれて初めて表に出ます。公開して直すサイクルの速さが、この事例の要でした。
- **バズは持続しない。** 作者自身が、売上の大半が広告枠の月額契約だったことと、「持続しなかった」という自己評価を残しています。
